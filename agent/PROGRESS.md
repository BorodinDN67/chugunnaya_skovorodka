## Технические решения
- PCL GICP + кинематическая одометрия, 6DoF.
- Общие вычислительные компоненты для mapping и localization.
- Резервная оценка по odom при отказе регистрации.
- Контрольные карты сохраняются отдельно от основной.
- `MapManager` накапливает принятые облака в координатах карты. В режиме localization экземпляр фиксирует первую успешно загруженную PCD. Каталог карт передаётся через `MapConfig`, для Docker-стенда используется `/ros2_ws/maps`.

## Открытые вопросы и риски
- Совместимость QoS при воспроизведении. В MCAP нет статических TF. `T_odom_base` доступно из сообщения одометрии.
- Разреженность облаков и применимость GICP.
- Начальная поза второй записи.
- Искажения сканов в движении, динамические объекты.
- Достижение 14 Гц на доступном оборудовании.
- Наличие подтверждённого ground truth.
