# PROGRESS.md — состояние проекта

## Текущая цель
Получить рабочий end-to-end baseline: 3D mapping + localization на готовой карте, GICP scan-to-map с предсказанием по одометрии.

## Подтверждено на момент создания файла
- Изучена постановка задачи и бриф организаторов.
- Выбран базовый технический подход (см. AGENTS.md).
- В репозитории есть отдельный стенд воспроизведения KISS-ICP. Его предыдущий прогон описан в корневом README. Результаты этого прогона относятся к KISS-ICP.
- Базовый стенд для `lidar_mapping` находится в корне командного репозитория `chugunnaya_skovorodka`. Оригинальный Compose монтирует его `ros2_ws` в `/ros2_ws` контейнера `r_hacatonius`. Соседний checkout `hackathon` сохранён как резервная копия.

Собрать пакет и выполнить модульные тесты внутри исходного Docker-стенда. Затем проверить данные, метки времени и TF по первому пункту чек-листа и провести отдельную проверку GICP на реальных сканах в порядке этапов выше.

## Технические решения
- PCL GICP + кинематическая одометрия, 6DoF.
- Общие вычислительные компоненты для mapping и localization.
- Резервная оценка по odom при отказе регистрации.
- Контрольные карты сохраняются отдельно от основной.
- `MapManager` накапливает принятые облака в координатах карты. В режиме localization экземпляр фиксирует первую успешно загруженную PCD. Каталог карт передаётся через `MapConfig`, для Docker-стенда используется `/ros2_ws/maps`.

## Открытые вопросы и риски
- Версия ROS 2, зависимости, реальные типы сообщений, QoS и TF.
- Разреженность облаков и применимость GICP.
- Начальная поза второй записи.
- Искажения сканов в движении, динамические объекты.
- Достижение 14 Гц на доступном оборудовании.
- Наличие подтверждённого ground truth.

Отклонённая регистрация использует предсказание с обновлением опорной одометрии. Диагностика учитывает потери, метрики и время этапов.

## Команды воспроизведения
При запущенном стенде войти в контейнер:

```powershell
docker exec -it r_hacatonius bash -l
```

В контейнере:

```sh
cd /ros2_ws
colcon build --packages-select lidar_mapping --cmake-args -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
colcon test --packages-select lidar_mapping --event-handlers console_direct+
colcon test-result --verbose
```
