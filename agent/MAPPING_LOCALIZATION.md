# Полные прогоны Mapping и Localization

## Mapping на bag_for_mapping

Основной режим `gicp_mapping` с набором `map08` получил все 1688 сканов и 18 100 сообщений одометрии. Два первых скана предшествовали опорам одометрии. Инициализация заняла один кадр, приняты 1567 регистраций, отклонены 118 (113 по fitness, 5 по поправке). Для отклонённых кадров независимо подтверждено одометрическое предсказание и отсутствие записи в карту. Итоговая PCD содержит 23 585 точек по 189 ключевым кадрам. Время обработки скана p50/p95 — 40,62/65,68 мс, GICP — 38,14/61,69 мс.

| Сравнение в общей системе координат | IoU ячеек 20 см | Медиана расстояния от первой карты ко второй |
|---|---:|---:|
| GICP → Deskewed | 9,65% | 19,57 см |
| GICP → Odometry | 9,62% | 19,15 см |
| Odometry → Deskewed | 87,46% | 1,54 см |

В коридоре на 16,47 и 23,60 с прошли коррекции одного кадра 37,4 и 37,7 см. На 55,00 с медианное расстояние точек ключевого кадра до Deskewed выросло с 2,29 до 66,01 см. Максимальное накопленное отличие от одометрии достигло 12,49 м. Локальная приёмка GICP пропускала ошибки, которые накапливались и деформировали карту.

Повторный полный прогон с опциональным ограничением накопленного отклонения в режиме mapping ограничил отличие позы 11,95 см, но принял лишь 60 регистраций и построил 791 точку по четырём ключевым кадрам. В 981 кадре не хватало точек локальной карты. Защищённый режим экспериментальный и по умолчанию выключен. Обе GICP-карты сохранены для диагностики. Для локализации выбрана полная контрольная `map_deskewed.pcd`.

## Localization на bag_for_localization

Из контрольной карты заранее подготовлены 74 731 точка с вокселем 8 см. Локализация использовала один загруженный PCD. SHA-256 до и после совпал, обновлений карты — 0.

Начальная поправка второй записи относительно контрольной карты — `(-0,52; -0,20; 0) м` и `-2°` по yaw вокруг первой синхронизированной позиции. Для пяти отдельных контрольных сканов обрезанный RMSE снизился с 6,37 до 5,91 см, p90 расстояния — с 8,03 до 6,53 см. Доля попаданий в 20 см изменилась с 97,79% до 97,61%. Это проверка локальной геометрической гипотезы; подтверждённого эталона межсессионной позы нет. Начальную позу можно заменить вручную в YAML или параметром launch `initial_pose_xyz_xyzw`.

Из обработанных сканов на резких поворотах приняты 92/158, на участках ускорения — 54/107. В 86 обработанных сканах с высокой долей близких возвратов вне карты приняты 9, в 77 использован резерв. Эта выборка выявляет возможные динамические объекты и изменения сцены. Причину каждого остатка отдельно не подтверждали. При 1× зарегистрирована потеря синхронизации под нагрузкой и длительные серии резервных поз. Устойчивость на всей записи и на 14 Гц не подтверждена.

В выходном MCAP проверены 860 поз, 860 совмещённых облаков, 861 сообщение пути, 18 сообщений диагностики, две публикации карты и `/clock`. Для всех 860 поз записаны оба TF `map → odom` и `odom → base_link`. Подробные метрики и конфигурация сохранены вместе с MCAP.

Повтор запуска внутри `r_hacatonius` с подготовленной картой из архива:

```bash
source /ros2_ws/install/setup.bash
ros2 launch lidar_mapping localization.launch.py \
  config:=/ros2_ws/src/lidar_mapping/config/localization_bag_for_localization.yaml
```

```bash
ros2 bag play /ros2_ws/bag_for_localization --clock 100 \
  --topics /utlidar/cloud_base /utlidar/robot_odom
```
