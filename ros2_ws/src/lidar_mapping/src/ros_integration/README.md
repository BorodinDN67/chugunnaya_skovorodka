# Интеграция с ROS 2

`localization_node.cpp` декодирует `PointCloud2` и `Odometry`, проверяет
кадры и синхронизирует входы по `header.stamp` через `OdometryBuffer`.
Готовые пары передаются в ядро `ScanToMap`. Один экземпляр узла обрабатывает
одну последовательность с возрастающими штампами. Перезапустите узел перед
перемоткой или повторным воспроизведением bag. Команды и параметры описаны
в [README пакета](../../README.md).
