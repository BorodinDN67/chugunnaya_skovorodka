# Интеграция с ROS 2

Будущий адаптер будет передавать позы и временные метки в библиотеку `lidar_core` из [core](../core). Преобразование сообщений, синхронизация со сканами, управление ожиданием и сброс буфера при сбросе часов относятся к адаптеру. Типы сообщений и преобразования между системами координат определяются после проверки записей и TF.
